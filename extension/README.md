This is the basic chrome extension specifically made for Trading View website. 

To use it:
1. Clone the Repo
2. Open Chrome extension manager
3. Toggle the developer mode ONN from top right corner
4. Click load unpacked and select the extensions folder in the repo. 
5. Pin it to the taskbar
6. Go to TradingView website, open a chart for a ticker and click on extensions icon.
